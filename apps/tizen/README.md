# Cabinet for Samsung TV (Tizen)

A Tizen web-app package that puts Cabinet's TV Mode on Samsung Smart TVs.

## How it works

Tizen apps can be *hosted* (remote start URL) or *packaged* (local files in a
`.wgt`). Samsung's hosted apps **don't support Tizen APIs** — and Cabinet needs
`tv.inputdevice` to register the extra remote keys. So Cabinet uses a hybrid:

- **`index.html` (packaged)** — registers remote keys (Channel ±, media keys,
  colour buttons), listens for `keydown`/`keyup` and forwards them into the
  app frame as `cabinet-tv-key` postMessages. The Back key exits the app.
- **The hosted Cabinet TV app** (`https://cabinet-eta-gilt.vercel.app/tv`)
  runs in the frame. `TizenKeyForwarder` turns the postMessages back into
  window key events, so TV Mode navigation works unchanged.

This split also means the TV app updates with every web deploy; only the shell
package is installed on the TV.

## Files

| File | Purpose |
|---|---|
| `config.xml` | Widget manifest: app id `CabinetTv1.cabinet`, `tv-samsung` profile, `internet` + `tv.inputdevice` privileges, access/allow-navigation for the Cabinet origin and the EmulatorJS CDN |
| `index.html` | Packaged shell (key registration + forwarding) |
| `icon.png` | 512×512 app icon — the Cabinet power-symbol mark (regenerate with `node ../../scripts/gen-tizen-icon.mjs`) |
| `build.sh` | `tizen build-web` / `package` / `install` helper |

## Build & install

1. Install **Tizen Studio** (or the VS Code Tizen extension) with the **TV
   Extension** and **Samsung Certificate Extension**.
2. Create a Samsung certificate profile (author + distributor). For sideloading
   to your own TV, the distributor certificate needs the TV's **DUID**
   (shown in *Device Manager* after connecting).
3. Enable **Developer Mode** on the TV (Apps → press `12345` on the remote →
   Developer Mode on → enter your PC's IP) and restart the TV.
4. Build and install:

   ```sh
   TV_IP=192.168.1.50 ./build.sh install
   ```

   Or step by step: `tizen build-web -- .`, `tizen package --type wgt --sign
   SamsungProfile -- .buildResult`, `sdb connect TV_IP:26101`, `tizen install
   -n .buildResult/Cabinet.wgt -t TV_IP:26101`, `tizen run -p
   CabinetTv1.cabinet -t TV_IP:26101`.

5. Point `index.html` at your own deployment if you self-host — the frame `src`
   is the hosted Cabinet TV URL.

## Notes & limits

- **Engine**: recent TVs run Tizen 9 (Chromium M120) / Tizen 10 (M130); the app
  targets 1080p landscape. Older TVs may lack `canvas.captureStream` etc.
  (only relevant for netplay from a TV).
- **Cookies / login**: the frame loads a remote origin, so signing in works
  exactly like on the web; the shell itself never sees cookies.
- **Store submission** (Samsung Seller Office) is a separate review flow with
  its own listing assets (1920×1080 and 512×423 images).
- The icon is generated by `scripts/gen-tizen-icon.mjs` — edit the colours
  there if the brand changes.
